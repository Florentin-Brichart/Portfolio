## Projets
### Washington_real_estate
[Vers le dossier du projet](Project/Washington_real_estate/Real_estate.md)
- Mots clés : Regression, EDA, Missing values, Text data, Merged dataset, ML supervised, Real estate
- Libraire : Pandas, Numpy, Seaborn, Sklearn, Linear regression, Random forest
- Résumé : 
    C'est un projet de régression sur la vente de propriété aux Etats-Unis (etat de Washington). L'objectif est de prédire le prix de vente des biens en se basant sur différentes variables : localisation, caractéristiques du bien ou encore données financières. Il y a 2 variables textuelles et 14 variables quantitatives en plus d'informations recherchées sur Internet (jeu de données supplémentaire sur les villes des Etat-Unis).
