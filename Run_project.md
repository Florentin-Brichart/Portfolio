# Installation

## 1- Ouvrir un éditeur de code
Ouvrir un éditeur de code (par exemple Vscode)   
Lancer un terminal

## 2- Cloner le dépôt
git clone https://github.com/Florentin-Brichart/Portfolio

## 3- Créer et activer un environnement virtuel (venv)
python -m venv env **(utiliser python 3.10 ou 3.11)**

source env/bin/activate # Pour Linux/macOS

env\Scripts\activate # Pour Windows

## 4- Installer les dépendances
pip install -r requirements.txt

## 4- Lancer le notebook
Ouvrir le notebook   
Utiliser env pour lire le code   
Lancer le notebook
